Programa

The open source terminal for running many coding agents at once and always knowing which one needs you. Native macOS on Ghostty, native Windows on WinUI.

  • Download for Mac
  • Windows preview
  • Source on GitHub

macOS 14 or later. The Mac app updates itself. The Windows app is in development: desktop interaction testing and macOS feature parity are incomplete. Free and open source under GPL-3.0.

Know which agent needs you

  • Every workspace shows working, blocked or idle. Claude Code, Codex and OpenCode report it directly; Gemini CLI, Copilot CLI, Cursor Agent and Aider get it from reading the terminal screen.
  • A waiting agent's pane gets a ring, its tab lights up, and ⌘⇧U jumps to the latest unread.
  • A vertical sidebar shows the git branch, PR status, working directory, listening ports and latest notification for every workspace.

Review and branch

  • A diff review panel beside an agent's terminal: comment on the diff and send the comments straight into the agent's input.
  • programa worktree create checks out a git worktree and opens it as its own workspace.
  • programa race fans one prompt across several agents, each in its own worktree, so you can compare approaches.

Native and scriptable

  • Swift and AppKit with libghostty rendering, no Electron. It reads your existing Ghostty config for themes, fonts and colors.
  • Relaunch restores layout, directories and scrollback, and terminal processes survive Programa quitting or crashing.
  • A CLI, a Unix-socket JSON-RPC API and an MCP server, so agents can split panes and read a sibling pane's output.
