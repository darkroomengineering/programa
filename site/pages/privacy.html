Programa privacy policy

Programa does not collect personal data. It has no accounts, no analytics and no crash reporting, and Darkroom Engineering runs no server for it. Your terminals, sessions and settings stay on your computer.

Updates. Once a day the Mac app downloads the update feed from the Programa releases on GitHub, and downloads a new version when there is one. It sends no system profile with the check. GitHub sees the request like any other download, under GitHub's privacy statement.

Pull request status. To show a branch's pull request and checks in the sidebar, Programa runs the GitHub CLI (gh) installed on your computer, signed in as you. Those requests go from your computer to GitHub, the same as running gh yourself.

What runs in it. The agents and programs you start in a Programa terminal make their own network requests under their own policies. Programa does not send their output anywhere.

Questions: open an issue on GitHub.
